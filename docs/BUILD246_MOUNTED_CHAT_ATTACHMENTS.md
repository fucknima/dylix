# Build246：签名提示复制标识与挂载附件入口

版本保持 Dylix 1.1.1，构建号为246。

## 修改

1. 签名标识明确不匹配且描述文件包含固定应用标识时，提示框增加“复制描述文件 Bundle ID”。复制的是去掉 App ID 前缀后的标识，可用于重签名；通配或未知标识不提供不可靠的复制值。原有自动检测、未知静默及继续选择保留。不恢复自动文件日志。
2. 会话“添加附件 → 挂载文件夹”可以浏览已授权目录，选择单文件。文件经安全作用域、NSFileCoordinator 复制后，复用现有附件导入和发送解析流程。临时副本在异步导入完成后清理，压缩包需要密码时在取消或最终完成后清理。
3. 进入挂载根目录后可点右上角确认，附加整个目录引用。目录采用按需只读访问，不批量上传。为会话建立独立授权引用，撤销会话引用不影响全局挂载。选择附件时禁止左滑删除全局挂载，并在新增授权结束后保留取消按钮。

## AI 与终端边界

- 既有 AI 运行时会把有效全局挂载加入附件授权清单，提供 read_attachment 的 list/search/read/inspect。单文件附件复用发送前解析，不把未经解析的草稿记录直接当工具引用。
- Linux 沙盒已有 /mounts/<授权ID> 只读入口，适合读取受大小及类型限制的文本。大文件、二进制可显式复制到沙盒后分析。
- 挂载不等于允许修改源目录；工具输出中的内容在实际读取后可能提供给模型。仍遵循会话权限和现有类型、敏感文件、路径及大小限制。
