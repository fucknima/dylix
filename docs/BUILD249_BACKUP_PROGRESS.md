# Build 249：备份大小、耗时与进度

版本 1.1.1，构建 249。

- 数据分类名称后显示压缩前大小；选择立即更新已选分类数量、总大小及预计时长范围。
- 大小扫描在后台执行，遵循备份分类路径、项目缓存排除、符号链接与外部授权排除规则；包含对应偏好设置 JSON。不读取钥匙串来估算，明确不含可选密钥、清单等开销，压缩后大小以完成结果为准。
- 移除右上角分享式创建入口，使用底部常驻“立即备份”按钮；恢复使用同位置的“恢复所选内容”。处理中禁止重复启动。
- 真正按复制字节、压缩字节及加密字节更新 NSProgress。复制/校验、压缩、加密分别占45%、45%、10%（未加密时压缩覆盖剩余部分）。进度只能单调增长，文件完成发布后才显示100%。显示处理阶段、百分比、已用时间及估算剩余时间。
- 启动前时长由总字节数、文件数、加密开销估算，显示范围；运行后按已用时间与处理进度更新剩余时间。这不是保证完成时间，设备性能和数据可压缩性都会影响实际耗时。
- 完成后显示备份实际大小、用时，文件先保存本机，再提供“保存或分享”选择，不自动弹系统分享。
- iPad 分享及历史操作菜单锚定底部按钮，避免移除右上角按钮后出现无锚点弹窗。
