# Build236 / FLEX 1.0.3

- 保留三指长按，同时新增四指长按，均为 0.5 秒触发。
- 两个独立识别器均允许与宿主/其他插件的手势同时识别，不阻断宿主触摸事件；FLEX 自身的两个入口互斥，避免同一次长按打开后又关闭。
- 插件源码和内置 FLEX 工程模板同步更新，重复初始化不会重复安装手势，窗口迁移时两个入口一起迁移。
- 独立 dylib、rootless deb 和 App 内置包同步为 1.0.3；App 为 1.1.1 Build236、SDK26.0。

验证命令：`python3 tests/FlexActivationGesturesRun.py --device <simulator-UDID>`。

iPhone 和 iPad 的 iOS18.3 模拟器均通过 21 项检查。使用生产激活识别器和实际 UIKit 触摸事件，验证三指、四指、长按不重复触发、短按不触发、双指不触发、其他三指手势提前识别、窗口迁移。仅测试用事件注入器放宽为四指，不扩大 AI 工具的生产触摸权限或数量限制。

DEB 内 dylib 与独立分享 dylib 哈希一致；插件和 App 的本地签名完整性检查通过，IPA 内置 manifest 和模板核对通过。未验证真机上的所有第三方插件组合或系统手势拦截。
