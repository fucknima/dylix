# Dylix 1.1.1（258）存储与备份修复验收

## 故障根因

清理前反复扫描 App 数据与选中目录，增加了耗时；清理期间关闭整个窗口交互，导致不能滑动。旧逻辑尝试删除 Library/Caches 系统容器本身，可能触发权限失败。Linux、备份、下载资源和恢复工作区等混入大类，造成占用不透明。

## 本次修改

1. 清理在后台执行，仅核验选中项；保留 Caches 容器、清理其内容，避免重复父子项。显示阶段和完成项数，允许当前项结束后停止；某项失败继续处理其余项并汇总。窗口保持可交互。
2. 拆分用户文件、接收/解包文件、本机备份、Linux 快照、终端输出、安装归档、下载资源、恢复工作区。保留分类也能查看实际目录和大小。未知 Library 数据保持只读，签名 App 资源不能直接删除；受管工具通过安装管理卸载。
3. Linux 当前环境提供重启后删除入口，执行前明确提示工具和环境文件会丢失；不额外创建快照占用空间。离线执行，保留项目与聊天。删除中断后继续完成，已经开始的删除不能取消。
4. 备份密码可记住并自动读取，保存于本机 Keychain；关闭记忆即删除。密码不进入偏好设置、日志或备份。换设备或签名后可能无法读取，请另行保存。
5. 立即备份改为列表底部可滚动按钮，避开常驻导航栏。本机备份进入独立列表和详情页，可查看、分享及删除。

## 验证结果

- 存储测试：57 项通过，包括缓存容器保留、分类、取消、权限失败后继续清理及受保护项。
- Linux 环境测试：32 项通过，包括删除计划、重启前不删、无新增快照、中断恢复和开始删除后禁止取消。
- 备份测试：48 项通过。
- iPhone iOS 18.3 模拟器原生回归：8 项通过。验证实际 Keychain 重读、常驻 Tab 栏下按钮不重叠、独立备份列表、5,000 文件清理时主线程与窗口可响应。
- iOS 26.0 SDK 真机目标编译成功；IPA ZIP 完整性、版本及 App 深度严格签名校验通过。签名为构建用 ad-hoc，不是用户安装证书。
- 早期模拟器运行曾遇到系统 Accessibility 初始化崩溃；去除测试内截图调用后，最终 iPhone 回归通过。可选 iPad 回归超时，未计为通过。

## 验证边界

没有在用户的 iOS 27.0.1 真机上实测，不能承诺删除 5 GB 的具体速度。大量小文件仍需系统逐个删除；停止在当前项结束后生效。没有把未识别数据或签名资源变成可任意删除。
