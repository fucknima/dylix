# Build264：更新提示与忽略版本

Dylix 1.1.2（264），FLEX 维持 1.0.3。

- 每次进程冷启动检测一次官网版本；普通后台返回前台不重复请求或弹窗。
- 官网版本较新时提供“更新”“稍后”“忽略此版本”。“稍后”不记住选择，下次冷启动仍可提示。
- “忽略此版本”保存至本机偏好；该版本不再自动提示，但继续检测，后续新版正常提示。数值等价版本（如 1.2.0 / 1.2.0.0）视为同一版。
- 关于页手动检测不受忽略限制，仍可查看并更新。
- 启动检测遇到其他弹窗或转场时短暂延后展示，最长等待60秒，不覆盖其他提示。检测失败或官网不是新版时静默。
- 点击更新仍只打开官网获取界面，不自动下载 IPA。

验证：版本、来源解析及官网 HTTPS 检查22项通过；原生生产更新界面使用固定新版响应，验证冷启动去重、弹窗冲突、三个按钮、忽略、手动检测及真实进程重启后忽略持久化。运行环境为 iOS18.3 ARM64 iPhone/iPad 模拟器，不冒充 iOS27 真机测试。
