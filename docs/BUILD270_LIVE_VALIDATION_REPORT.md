# Build270 真实中转 API 补充检验报告

日期：2026-11-12。用户提供测试 API 后补做。此前离线报告的“没有在线验证”描述仅适用于当时；本报告增加真实网络调用，但仍不能给生产循环概率。

## 方法与验收边界

接口为用户指定的 https://o10.top/v1/chat/completions。模型标识 gpt-5.6-sol、gpt-6-sol、gpt-6.1-sol；只能确认网关响应所声明的标识，不能独立核验中转站实际路由模型。全部走 Chat Completions，不能说测试了三种提供商协议。

每个标识：3 个任务 × 3 个种子 × 新旧两个版本，各版本 9 次；合计 27 对、54 次真实任务。三类任务为近期约 28 KiB 源码、重叠源码片段、历史读取后外部改动。每次是独立隔离文件，只授权修改该测试文件。

实际使用 Build269/270 的 AIRuntime 与上下文投影，网络使用专用 Chat Completions 适配器；工具端是真实读写隔离文件、精确提案与版本校验，验收比较目标结果及所有无关源码字节。未运行 App 的完整 iOS 生产 transport、UI、FLEX 或真机，未编译真实 iOS 工程。测试工具签名也比生产补丁工具精简，不能视为所有生产功能端到端验证。

完成定义：文件实际正确、模型实际调用验收工具并通过、运行时 completed，三者同时满足。工具成功后最后回答因 503 中断也计整体失败，另列文件正确数。

各任务最多 16 次请求、每请求 max_tokens=1200，不自动重试 API 错误；温度及推理参数用服务端默认，未指定 seed，因此属于相同任务/配置的配对观察，非确定性因果试验。累计 token 包含工具结果、纠偏及最后回答，读取缓存以服务端 usage 为准。

先导 6 次使用 8 请求上限，发现会人为截断旧版后统一改为 16 再正式重测。先导结果单独保留，不混入正式成功率。另有连接探测 gpt-5.6 返回 503，未选入正式模型。

## 限制与结论

这次补上了真实网络模型决策，但样本每模型每版本仅 9 次，未达到原方案每类 30 对；仅有三个任务类型，且没有专门诱发复杂长周期语义循环。历史回读次数不是循环事件次数，必要的新范围读取不算 bug。不能凭零次循环暂停宣布零循环或计算泛化的“剩余概率”。

线上数据可以支持近期原文保留在这些任务中的表现；无法证明长期会话、实际插件工程、所有模型、锁屏恢复都已验证。仍保留部分完成项：模型 token 窗口自动预算、跨会话诊断聚合、真实价格/费用验收。真实 token/缓存用量现已开始采集。

API 密钥仅在本机临时测试网关内存中使用；没有写入源码、配置、报告、日志或 IPA。本轮没有重新打包 IPA，也没有上传 GitHub。
