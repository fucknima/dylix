# Dylix 1.1.1（259）备份统计与进度布局

1. 移除备份页顶部状态区及固定空白。状态集中在底部按钮区域，使用两列居中信息：空闲时显示大小/预估耗时，进行时显示已用/剩余时间，阶段文字居中。
2. 立即备份按钮带图标，点击后准备阶段显示沿边框流动光圈，有实际进度后按进度描边。轻点可确认终止；尊重系统减少动态效果设置。常驻导航栏开启时按钮仍可见。
3. 统计改为物理文件树遍历，不逐文件重复解析完整真实路径；不跟随符号链接，保留项目缓存和目录授权过滤规则。小分类先返回，界面逐项更新。30 秒内重复进入复用结果，支持下拉刷新；预览不阻塞备份，正式导出仍重新扫描核验。
