## 先核实的差异

- 当前已有动态MCP function schemas、HTTP/STDIO及查询/控制分级授权（Build222），不是“只有只读参考文本”。P2-1做可靠性与缺失能力补齐，不重建客户端。
- 当前web_browse及sandbox_browser已有DOM交互和截图；P2-3重点是标签会话隔离、明确导航/修改边界、持久登录态的用户选择。
- 已有11项技能清单、正文查看及项目安装入口。P0-4新增便捷管理和guest只读访问，不重复技能解析器。
- 当前工具安装已有全局自动安装偏好、会话成功标记及重试。保留会话文件隔离，优化重复安装检测，不把全部会话根目录合并。
- 报告中“本机工具不够通用”不是本期扩展健康/日历/宿主Shell的依据；聚焦插件开发和逆向。

## 不变的约束

编译/Logos/双SDK/包布局/签名校验/REipa/radare2/libgit2不回退；项目根、链接检查、审批、钥匙串、用户技能与记忆不重置。构建始终单活。长会话摘要仅本地保存；不自动上传。现有只读目录授权不得升级成可写挂载。任何重置先备份，禁止删除活跃内核正在使用的fakefs。任务完成不意味着未经用户要求发布GitHub。
