# Dylix 1.1.1（263）：终端绑定与工作目录

1. 顶部紧凑显示所属 AI 会话、关联项目、交互终端/命令任务及工具全局共用；设置入口明确标为本机终端。AI 会话及项目入口传递可读会话标题，无法获取标题时保留短会话 ID，绑定详情可查看完整 ID。
2. 从选定 Shell 的 fs_info 读取实际工作目录，页面可见时每 2 秒刷新，不通过向终端注入 pwd 等命令获取，也不解析提示符。运行前保留 fs_info 引用并在完成后释放，避免读取已退出任务的裸指针。目录不可读时明确显示默认目录，不冒充当前目录。该值是选定 Shell 的目录，不是前台子进程的目录。
3. 菜单区分“连接会话终端”与“新建命令任务”。连接复用原 Shell；从任务页返回已有会话终端时优先复用导航栈页面。新任务提示独立 Shell、默认工作目录及不继承 cd/export/临时变量。进程列表区分交互终端和命令任务。
4. 点击顶部绑定信息可查看完整会话 ID、当前/默认目录、共享环境及进程生命周期说明，支持复制当前目录。AI 单次执行工具说明同步明确独立 Shell 与连接现有进程的区别。

## 验证

使用生产 runtime 和 UIKit/WebKit 终端代码，ARM64 iOS 18.3 iPhone 模拟器 8 项断言通过（另有完成标记）：启动 Shell、实际 cd 后显示 /tmp、重连复用原句柄和目录、拒绝其他会话读取句柄上下文、新命令使用默认目录且不继承临时变量、顶部绑定内容、顶部与终端布局不重叠、菜单区分两种操作。结果与截图随安装包交付。

测试期间执行真实 cd、export 和 Shell 命令。没有调用外部模型，不据此声称已完成 AI 端到端模型交互测试。未验证用户 iOS 27 真机。

发布构建使用 iOS 26.0 SDK；保留前序版本功能，未上传 GitHub。
