# Build235：附件气泡与底部导航栏

1. 新发送的消息分别保存用户可见文字和模型输入。内联文件源码、JSON 转义及项目上下文不再铺满气泡；附件卡片、预览、图片及按需读取引用保留。
2. 兼容旧附件消息：仅识别现有附件元数据对应的自动生成段落，不通过删除反斜杠或隐藏任意 JSON 修饰内容。载入旧消息时缓存可见文字，原始模型内容保持不变。
3. 复制消息、编辑并重发使用用户可见文字；重发仍保留原附件载荷，附件单独发送时不再出现“正在响应”占位。
4. 设置 → 外观与编辑器新增“始终显示底部导航栏”。默认关闭：根页面显示，项目/会话/设置内部隐藏；开启后始终显示，偏好持久保存并立即生效。
5. 统一普通导航栈和 iPad 分栏的显示规则。iPad 详情保留“主页”入口；修复在紧凑布局切换标签后立即打开会话时误送入分栏详情的问题。
