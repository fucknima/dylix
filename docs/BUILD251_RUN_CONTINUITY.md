# Build 251：执行防循环、会话补充和中断续接

版本 1.1.1 / 251，设备构建使用 iPhoneOS26.0 SDK。

## OpenMinis 对照

核对仓库 https://github.com/OpenMinis/OpenMinis ，HEAD `1a71df0f381cefde80bf912b723de6f9831bc177`。
阅读 `src/ios/Agent/Chat/AIChatViewModel+PromptQueue.swift` 的独占 drain、晚到消息交接，以及 `AIChatViewModel+BackgroundTask.swift` 的后台到期挂起与恢复处理。使用 Dylix 原有 Objective-C runtime 实现，未复制上游 Swift。

## 改动

- 原始调用名+排序参数与稳定结果的 SHA256 指纹保留在本轮有界索引（最多 96 条），不把调用 ID 当重复判断依据。忽略 duration、timestamp、export_id 等易变元数据。连续 6 次已见且未变的非轮询结果提示收尾，12 次暂停；同一路径内容变化和新查询重置计数，不设置任务总轮数上限。进程/FLEX实时轮询豁免。
- 最近 8 条构建/补丁/导出等关键回执的短索引作为本轮请求系统上下文保留，完整结果仍使用原始 result ref 按需读取。续接从本机原记录恢复索引；不是把产物存在当作任务完成或真机验证通过。
- 会话执行中发送文字补充（单条 64 KiB、最多 16 条待接入），立即显示并检查点保存。在当前模型响应/工具完成边界接入；旧批次中尚未执行的调用关闭为 notExecuted 并重新规划。审批后执行前再检查补充队列。已执行操作不回滚，也不承诺撤销正在运行的操作。
- 独立停止按钮，不再把发送按钮直接变成停止。空输入时暂停/中断显示继续按钮，菜单保留继续入口。手动停止保留已收到结果与排队文字，不自动恢复。
- 后台执行额度到期及后台期间的传输失败保留部分回复和工具结果。返回前台最多自动续接一次；重复失败保留手动继续，不循环重试。继续处理遵守当前会话权限；未完成工具结果标记 outcomeUnknown，要求先只读核对，禁止盲重放。重启恢复不持久化执行权限。
- 本轮运行中追加仅支持文字；附件需在任务结束后发送，未发送附件保留。

## 验证

- `RunContinuity251Run.py`：执行中补充、检查点、审批前旧计划拦截、文本尾部队列、手动停止、过期流回调忽略、后台到期部分输出、交替重复读取防循环、有变化的长任务、实时轮询、续接产物索引。
- 使用用户导出的真实会话在本机回放 429–553 条重复读取片段，新保护在原用户介入前暂停。导出会话未复制进源码/安装包。
- `AIRuntimeBudgetRun.py`：40轮及1200个持续有变化的工具结果通过；旧假结果改为随执行变化，区分合法长任务和空转。
- `ContextRuntimeRun.py`、`AIRecoveryRun.py` 通过。
- iPhone16ProMax/iPadPro iOS18.3模拟器：`RunContinuity251UIRun.py` 各12项通过，覆盖补充发送、停止独立、手动继续、后台续接、草稿保留、自动失败限次。

范围：未做 iOS27 真机锁屏实测；系统后台时间和强杀不能由客户端保证。续接是带已保存记录的新请求，不是恢复服务端断开的同一 SSE 流。防循环是精确参数/稳定结果检测，不能穷尽改写 shell 命令或语义等价的不同调用。
