# Build 257 · 文件分类整理

## 原因与修改

这不是编码乱码，而是内部 UUID 工作目录与用户文件混放在 Documents，直接出现在系统“文件”App 中。

- 接收文件：原文件名、时间与短编号命名，保留原始内容；旧 Incoming 记录自动迁移并同步更新接收记录。
- 构建产物：项目或产物名称、时间命名，包含 deb、dylib、构建日志和构建报告。
- 头文件导出：应用名称、时间命名的 ZIP。
- Projects：继续保存正常项目源码。
- UUID 构建、快照、分析输入和历史导入工作目录标记为隐藏；内部路径、任务 ID 和会话引用继续有效。并非已经把这些数据搬到 Library。
- 存储空间使用元数据展示可读名称，并可单独清理构建导出副本。备份覆盖三个新分类。

已存在的导出副本不覆盖，已删除的副本不在启动时自动生成；文件复制采用临时文件完成后原子移动，并拒绝符号链接目标。整理与发布序列化，避免启动维护与构建完成同时执行时生成重复目录。

## 验证

- 文件整理：macOS Foundation 27 项通过；iOS 18.3.1 模拟器原生运行同样 27 项通过，隐藏过滤正常。
- 系统“文件”App：实际打开验证应用 Documents，确认根目录仅为分类目录及说明，接收记录展示原文件名和时间。截图 files-root.png 使用隔离测试应用，非用户真机数据。
- 备份：48 项通过，包含新增分类文件的打包和恢复校验。
- 存储空间：42 项通过。
- 会话 ZIP：导出恢复、资源、图片、工具记录、新 ID、权限重置及非法 ZIP 拒绝通过。
- 二进制与接收流程回归通过；会话附件及导航集成 21 项通过。
- 真机安装包使用 iPhoneOS 26.0 SDK 构建，版本 1.1.1 (257)，发布版；需使用自己的安装方式重新签名。

未宣称已在用户 iOS 27 真机验证。系统“文件”隐藏行为已在 iOS 18.3.1 模拟器验证；其他文件管理器可能选择显示隐藏目录。导出文件为独立副本，会增加相应磁盘占用，可在存储空间删除。
