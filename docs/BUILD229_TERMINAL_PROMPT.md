# Build229：终端身份提示符

将启动环境中的 `PS1` 从仅目录和固定 `$` 改为 `\u@\h:\w \$ `，由 Shell 展开实际用户、主机名、当前目录及身份符号（root 为 `#`）。适用于新启动的交互终端与受管理 Shell，不改变用户身份、主机名、授权或文件访问范围；已经运行的 Shell 保持原环境，需退出后重新打开。

增加真实 iSH 交互 PTY 提示符回归，保留既有交互输入和终端 WebView 验证。

验证结果：115 项回归全部通过，交互提示符、PTY 输入、WebView 显示通过。iOS26 SDK 构建 Build229 成功，IPA 完整性和 App deep/strict 签名检查通过。
