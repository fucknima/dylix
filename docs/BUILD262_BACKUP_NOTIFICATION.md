# Build 262：备份完成提示去重

根因：DXBackupTask 单例保留完成结果，但 DXBackupPage 仅用页面实例属性 shownResult/shownError 去重；新页面丢失标记，重复展示历史任务提示。

修复：任务级别 claimCompletionNotification 只允许消费一次完成/失败通知；开始下一次备份时重置。页面不可见或已有弹窗时不消费；viewDidAppear 重试，支持离页期间完成后首次返回提示。结果仍保留，本机备份列表和分享不受影响。

验证：ARM64 iOS 18.3 模拟器使用生产备份任务与界面代码，注入确定的完成/失败状态，6 项行为断言通过：空任务无通知、不可见不消费、首次展示、重新创建页面不重复、新任务可提示、错误仅提示一次。本次验证聚焦提示生命周期，未重新运行整份备份/恢复套件，未声称用户真机已验证。

子代理代码核对：AIRuntime candidateSchemas 在支持工具调用且绑定项目时提供 subtask_task；start 不要求用户先说“子代理”。模型可决定调用，但没有强制自动派发调度器。目前 analysis/build 两种，最多每父会话 3 个，深度 1；使用父会话当前连接，独立受辅助权限控制，构建独立审批且串行；结果回到主会话参考，不能把启动当完成。App 重启后不自动重放。
