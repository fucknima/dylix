# Build 239：单会话 ZIP 与设置排序

- 设置「数据与工具」放在「关于」之前，「关于」保持最后。
- 会话列表长按增加「导出会话」，调用原生分享面板，兼容 iPad 弹出锚点。
- ZIP 包含 DylixSession.json 标识、完整 session.json，以及被会话引用、仍在本机的附件、二进制、头文件输入/导出、构建产物、解压附件目录、终端导出文件。不会打包整个工程、Linux 根文件系统或外部挂载目录。
- 分享 ZIP 到 Dylix，通过现有文件接收链路自动识别、导入普通会话并刷新列表。生成新会话 ID 和资源 ID，重复导入不会覆盖旧会话。
- 内部解压附件目录重建文件身份信息；终端导出元数据关联新会话。外部目录授权、项目访问权、运行 checkpoint、连接身份、会话权限不迁移，不自动恢复执行。消息内用户主动写入的文字仍属于会话内容。
- 运行中的会话等本轮结束后导出。记录上限 32 MiB，资源总展开上限 512 MiB，10000 个资源文件。不包含已经删除的附件。系统分享完成/取消后清理临时导出包。
- 导入拒绝路径穿越、重复条目、符号/硬链接、加密 ZIP、不在资源允许目录内的条目、损坏压缩数据及超限数据。先完整解包验证，再复制资源，复制失败回滚本次文件。
