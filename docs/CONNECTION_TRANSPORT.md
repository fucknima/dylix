# 模型连接：请求头与 HTTP

Build225 更新。入口：设置 → AI → 模型连接 → 选择连接 → 传输与请求头。

## 自定义 HTTP Headers

使用 JSON 对象配置，例如 `{"X-Client-Name":"my-client"}`。请按实际服务文档填写，不内置其他客户端身份，也不保证服务商允许第三方客户端。`Authorization` 可显式覆盖默认 API Key 鉴权；其他自定义头在默认协议头之后附加。User-Agent 仍使用专用入口。官方 OAuth 不附加这些头，切回 API Key 时保留配置。

最多32项，每个值最多4096个可打印 ASCII 字符，总计16KiB。拒绝大小写重复、CR/LF、控制字符，以及 Host、Content-Length、Connection、Content-Type、Accept 等由传输层管理的字段。空对象 `{}` 清除。

值存入独立钥匙串服务，不进入连接偏好设置、模型消息或工具连接列表。设置页只显示数量，进入编辑器才显示值。删除连接同时清除请求头凭据。读取失败或凭据丢失时停止请求，修改或清除后使旧能力验证失效。模型发现（含分页）、能力测试、普通/流式对话使用同一组请求头；只在精确同源重定向保留，跨域/协议/端口变化不转发。测试诊断对回显的请求头值脱敏。余额接口不附加自定义头。

## 自订 User-Agent

每个连接可以填写单行User-Agent。留空使用系统默认；最多512个可打印ASCII字符，换行、控制字符与非ASCII输入在保存和请求前被拒绝。设置用于该连接的模型列表发现、能力探测、对话及同源重定向。无需把User-Agent放进Base URL、模型名或API密钥。

它是普通客户端标识，不是鉴权凭据，也不保证服务商会接受请求。切换模型仍沿用该连接设置；按项目覆盖的连接选择规则保持原状。修改User-Agent或HTTP权限后清除旧能力探测结果，重新测试。

## HTTP API

Base URL 可填写HTTP。每条连接的 HTTP 权限默认关闭，地址可先保存，实际请求前检查授权。

- “仅允许局域网 HTTP”：接受 localhost、127/8、10/8、172.16/12、192.168/16、169.254/16、.local，以及 IPv6 ::1、fc00::/7、fe80::/10 和映射的私有 IPv4；不允许公网 HTTP。启用前提示 HTTP 不加密，仅用于可信局域网。地址准入为主机名/字面地址校验，不对 DNS 解析后的目标提供隔离保证。
- “允许任意主机 HTTP”：沿用旧版显式权限，包含公网，单独确认明文风险。已有连接不会被重置或缩小权限。

启用其中一档时关闭另一档；关闭只撤销对应档位。HTTPS 请求不受这两个开关影响。

HTTPS原有行为不变，OAuth连接继续要求HTTPS。App的ATS采用通用HTTP传输例外，以覆盖用户输入的任意HTTP主机；细粒度准入由模型传输代码按连接执行，ATS本身不是每连接授权机制。未关闭HTTPS证书校验。

同源比较采用实际协议、主机和有效端口：HTTP默认80、HTTPS默认443；跨域、跨协议、端口变化和改变请求方法的重定向被拒绝。HTTPS不会自动回落HTTP。远程网页只使用手机保存的连接，API密钥、OAuth token和User-Agent配置不返回网页。

Dylix Remote 的局域网HTTP服务与模型API连接是两条独立链路；打开其中一个不自动授权另一个。TLS保护网页/服务传输，User-Agent用于标识客户端，两者用途不同。
