# Build 250：独立备份任务与官网更新检测

版本保持 1.1.1，构建号 250。

## 备份任务

- 新增 DXBackupTask 单例，任务、NSProgress、开始/完成时间、结果及错误由任务管理器持有，不依赖备份页面。
- 返回 App 其他页面继续执行；原页面可以释放。再次进入备份页接回同一任务与进度，底部显示“终止备份”。终止前确认，不删除已有备份。
- 任务开始时复制分类和密码，在工作线程持有原有项目写锁；重复启动被拒绝。完成后回到主线程发布状态。
- 申请 UIApplication 后台任务时间；到期主动取消并清理。系统可能暂停或终止应用，不能保证无限后台运行。划掉 App 会终止进程，不提供跨强退断点续备份。
- 完成用时取任务实际结束时间，避免返回页面后把等待时间计入备份时长。

## 更新检测

- “关于 Dylix→版本”现在可点击，显示检测中、最新版本/新版本及失败提示。
- 每次进程冷启动检查一次，不因页面切换或返回前台重复检查。失败不阻塞启动，手动检测可重试。
- 只请求 https://dylib.cn/ 首页，从真实 `<a href>` 的 `/downloads/Dylix-版本号.ipa` 文件名读取版本；支持构建后缀，按数字段比较，拒绝营销文案、其他应用与非官方地址。不会为检测而下载 IPA。
- 官网目前真实地址为 https://dylib.cn/downloads/Dylix-1.1.1.ipa，识别版本为 1.1.1。版本号相同不会因 App 构建号不同提示更新。
- 点击更新在 App 内打开官网，执行官网“获取 Dylix”按钮以展开原有弹窗；不自动点击 IPA 下载链接。下载按钮必须由用户主动点击。
- WKWebView 禁止非用户动作打开 IPA；用户主动点击官方 IPA 链接后交系统浏览器处理。
- 当前官网结构不需修改或部署新后端；若以后修改页面按钮或下载文件命名，需要相应更新适配。
