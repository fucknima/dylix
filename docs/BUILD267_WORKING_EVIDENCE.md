# Build267：工作证据保留与重复读取治理

目标是让模型在历史压缩后继续已有工作，而不是通过反复暂停让用户催促继续。

## 核对的参考实现

- OpenMinis `src/ios/Agent/Chat/AIChatViewModel+Compaction.swift`：压缩摘要保留请求、已执行操作、结果、文件和决策；摘要仅为历史，最新用户消息优先；明确不要重新运行发现流程。核对原始源码：https://github.com/OpenMinis/OpenMinis/blob/main/src/ios/Agent/Chat/AIChatViewModel%2BCompaction.swift
- DeepAgents `middleware/summarization.py` / `filesystem.py`：摘要与保留的近期消息组合；大结果卸载时保留预览和可回取位置，按需读取。核对原始源码：https://github.com/langchain-ai/deepagents/tree/master/libs/deepagents/deepagents/middleware
- Dylix 没有直接移植上述实现或增加每轮付费摘要请求；采用适合现有 Objective-C 数据结构的确定性工作证据。

## 实现

1. 压缩历史时额外保留最多 8 项工作证据：近期源码原文、路径、起始行、版本、结果引用，及最多 3 页已有历史原文。源码/历史证据预算 24 KiB，每项上限 12 KiB；最终仍服从用户的整个请求保护预算。不是只剩工具引用目录。
2. 已确认的文件修改、构建/导出返回事实也可进入工作证据。不从普通文本推断成功，不宣称整项任务或真机验证完成。
3. 反向遍历时过滤成功修改前的旧源码；仅失效修改文件，保留无关文件证据。快照只是历史，不保证外部文件未发生变化。
4. 删除“逐个回读归档”式诱导文字。明确先复用现有证据、只补真正缺失的范围；不因一个小修改重新调查整个项目。
5. 源码按文件版本与行号内容识别覆盖。改变 start_line/line_count、历史引用或搜索词不再自动成为新证据；90% 以上已知行的高度重叠页计入重复，正常向后分页仍可用。
6. 已有循环暂停作为最后止损保留，正常长任务不受总轮数硬上限限制。
7. 最近 512 条历史用于恢复观察状态。行证据上限 16000 行、48 个文件版本，常规观察键上限 192；避免检测器自身无限增长。
8. 工作证据仅生成在发给模型的投影里，不修改原始会话、消息序号、附件或可回读原文。

## 验证与边界

- 用户会话原件只用于本机离线回放，不放入源码、安装包或公开测试夹具。
- 实际会话投影验证：压缩后保留工作证据，而不只保留回读引用。
- 回归覆盖：行范围变化、无关文件写入、修改文件复查、文件版本变化、正常新分页、历史原文回读、精确原文恢复、权限与不完整工具批次。
- 使用真实会话的工具结果回放不会执行其中的修改、构建、Hook、网络或其他工具指令。
- 离线回放验证检测和上下文组织；没有使用用户的实际供应商账号重新运行模型，因此不能宣称真实模型在所有任务中零重复。
