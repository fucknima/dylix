# Dylix 1.1.1 更新内容

汇总 Build212–223，发布构建 Build225（包含连接修复）；配套 FLEX 插件 1.0.2。

1. 新增独立 Linux 终端，集成 iSH、Alpine 和 PTY；支持文件持久化、交互进程、离线开发工具安装，AI 可执行命令、持续读取输出和管理任务。
2. 完善附件与文件管理，支持 deb 解包、单文件正文读取，以及目录浏览、编辑、搜索、多选复制移动、导入导出和审核后写回项目。
3. 接入 Ghidra／radare2 反编译，支持近似 C、ARM64／arm64e 反汇编、函数、控制流图、交叉引用和 P-code，支持任务取消、结果分页与导出。
4. 完善浏览器和本地网页预览，AI 可读取 JavaScript 页面、观察控件、点击、输入、选择、滚动和截图，并复查操作结果。
5. 完善 MCP，新增 Linux STDIO、配置向导、依赖检测、会话选择和连接诊断；修复查询工具误锁，设备交互工具可手动启用并经确认调用。
6. FLEX 更新至 1.0.2，连接保留局域网与无需 Wi-Fi 的本机模式；日志取消整份文件 64 KiB 限制，默认读取 128 KiB、单次最高 512 KiB，支持末尾读取和分页续读。
7. 内置技能扩充至 11 项，覆盖插件开发、Hook、打包、Mach-O、反汇编、反编译、FLEX 取证、崩溃与混淆分析等，正文按需加载。
8. 修复终端误报内存不足、日志续读卡住、工具安装重试等问题；完善输出缓存与落盘、远程取消和撤权检查、凭据脱敏及资源回收。

9. 模型连接新增自定义 HTTP Headers，值存钥匙串；新增“仅允许局域网 HTTP”开关，支持私有 IPv4/IPv6，保留原有 HTTP 授权。补齐 GitHub #1 的请求头配置能力及 #3 的局域网设置入口；OpenCode Go 真实账号仍需实际验证。两组回归共329项通过。

主程序与分享扩展使用 iOS 26 SDK；LiveActivity 使用现有 Swift 工具链 SDK。IPA 为 ad-hoc 校验产物，普通签名安装须自行签名。模拟器、静态与本地 HTTP 测试不能代替所有真机、宿主 App 与第三方 MCP 服务验收。反编译返回近似结果，不保证恢复混淆或加密程序的原始源码。

完整源码包含 `Plugins/FLEX`（1.0.2），另提供单独的 FLEX 1.0.2 源码压缩包、dylib 和 deb。
