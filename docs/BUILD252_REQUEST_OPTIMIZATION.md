# Build 252：请求开销与回答优化

依据用户提供的《Dylix-AI-费钱啰嗦-原因分析与优化清单》，保留 Build 251 的历史落盘、原文回读、防无进展循环、执行中补充与中断续接。

## 本次实现

- AI 模型与连接 → 用量与账户 → 执行与回答：简洁、标准、详细三档。默认标准；按复杂度组织回答，减少逐条复述工具和无新信息播报。用户明确要求优先，不收紧模型输出上限。
- 可选工具按需加载：基础读工具常驻，search_tools 提供全部当前可用工具名称；按准确名称或关键词加载下一轮 schema，每次最多 12 个。已用工具从当前会话历史恢复，当前运行加载集合不递减。子任务保留原有直接工具白名单。关闭即回退全量工具。
- 发现工具只改变请求 schema，不改变权限。调用继续经过注册表、参数验证、实时可用性与原审批；工具禁用、前后台及附件授权变化仍生效。发现工具被项目禁用时回退全量可用 schema，避免能力被困住。
- 可选 Anthropic 官方短时缓存：仅 api.anthropic.com 的非能力探测 Messages 请求添加 ephemeral 断点；缓存标记置于开发提示词的易变环境快照之前。兼容中转、其他协议不添加新缓存字段；不开启付费保活，不改变模型、思考档位或输出额度。
- 修正中断续接指南过时的“只能只读核对”描述，保留先核对结果未知操作、不自动重放副作用的要求。

两个新优化开关默认关闭，避免旧会话、代理接口和不擅长工具发现的模型发生行为变化。回答默认标准。

## 验证口径

运行时工具发现到调用的完整流程使用真实 AIRuntime 与注册表，模型传输/文件执行为确定性 fixture；不冒充实际服务商任务成功率。
缓存测试检查实际协议请求 JSON，不声明真实缓存命中或账单节省。缓存最小长度、命中和价格由服务商决定。
iPhone/iPad 模拟器从生产设置页进入，切换并恢复设置；使用生产工具声明测量 JSON 字节，不能把字节节省比例当成实际付费 token 节省比例。

## 保留边界

不采用文档中默认降输出、固定 100 步截停、付费空闲保活等方案。没有引入收费模型摘要、价格表或自动换模型。原文、思考协议数据和用户权限不因此删除。
工具发现可能增加一次模型往返，短任务未必更便宜；首次发现后工具会继续保留。开启后如模型表现不佳，可关闭恢复全量工具。用户自定义人设关闭开发提示词时，尊重该选择，不强加内置风格提示。
